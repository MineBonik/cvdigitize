Calibrate
Auto-calibrate finds the axis frame + tick positions (no OCR) and shows a zoomed crop of each number below — read it and type the value. set pt then click the canvas to place/move a point by hand; drag an existing marker to fix it.
Measure (automatic)
Measures the curve's line width vs. the axis line's width, and computes the axis-exclusion band (faint red on the canvas) — the strip around the axes that extraction will ignore, so the axis itself is never traced as data.
Extract & check
Each curve is drawn emphasized on the canvas with a fidelity badge (how well it sits on the ink, reference-free). A red-dashed segment marks a chord jumping across empty space — re-trace by hand if the eye check doesn't look right, for any figure type.
